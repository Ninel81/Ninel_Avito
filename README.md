# Сайт Нинель Храмовой — авитолога

Статический сайт: HTML, CSS, JavaScript. Зависимости и сборка для Vercel не требуются.
Основной адрес: https://ninel-khramova-avito.vercel.app/

## Локальная разработка

```sh
cd /workspace/Ninel_Avito
python3 scripts/serve.py
```

Локальный сервер поддерживает URL статей без `.html`, как Vercel с `cleanUrls`.

## Контент и полуавтоматическая публикация

Статьи хранятся в `content/posts.json`. После подготовки и проверки материала:

```sh
python3 scripts/build_blog.py
```

Команда создаёт HTML статей, индекс блога, sitemap и llms.txt. Все результаты коммитятся вместе с источником. Команда повторяема; платные API не используются. Не удаляйте опубликованные slug без перенаправлений; для вывода старой статьи из публикации удалите также её HTML и настройте 301 в Vercel.

Перед публикацией проверьте факты, цены, правила Авито, ссылки, даты и отсутствие персональных данных клиентов. Для новой статьи используйте дату фактической публикации, а не будущую дату из плана. При содержательном обновлении существующей статьи укажите реальную дату обновления в `date` (поле сейчас служит единой датой материала). Не публикуйте вымышленные кейсы или отзывы. Пример расчёта в статье о бюджете явно обозначен как учебный.

Полуавтоматический режим: владелец выбирает тему из `docs/content-plan.md` и просит агента подготовить статью, проверить и опубликовать. Ежедневная генерация по расписанию, рассылки и автопостинг пока не подключены: для них нужны выбор сервисов, бюджет, авторизация и согласование обработки контактов. Никаких скрытых сборщиков контактов нет: форма создаёт текст локально, пользователь отправляет его в чат Авито.

## Vercel

Импорт `Ninel81/Ninel_Avito`, Production Branch `main`, Framework `Other`, Build Command пустой, Output Directory `.`. Настройки — `vercel.json`. Push в `main` инициирует deployment только при настроенной интеграции GitHub–Vercel; успешный push сам по себе не подтверждает публикацию.

## SEO и GEO

- Главная: конкретный H1, title/description, canonical, Open Graph, автор, города, FAQ.
- JSON-LD: Person, Service, WebSite, FAQPage; статьи: BlogPosting; индекс: Blog.
- `robots.txt` разрешает обход всем роботам. Это включает поисковых и AI-роботов, а также обучающих ботов, соблюдающих файл. Защита Vercel/CDN настраивается отдельно.
- `sitemap.xml` содержит только основные публичные страницы; `llms.txt` — дополнительный справочник, не стандарт с гарантированным эффектом.
- Не добавлены фиктивная организация, офисный адрес, рейтинг, фотографии, отзывы и достижения.
- Шрифты системные: сайт не зависит от Google Fonts. Основной контент и FAQ доступны без JS.

После смены домена обновите `BASE` в `scripts/build_blog.py`, canonical/og:url/JSON-LD главной и Sitemap в robots.txt; пересоздайте блог. Добавьте домен в Google Search Console и Яндекс Вебмастер под аккаунтом владельца, отправьте sitemap; права и подтверждение владения требуются отдельно.

Проверка рекомендаций: https://tenway.club/course/presentation-week2.html и https://tenway.club/course/presentation-week4.html (GEO-раздел), изучены 20.10.2026. План и ограничения — в `docs/implementation.md`.

## Визуальный стиль и кейсы

Светлые кремово-пудровые поверхности и тёмно-синие акценты общие для главной и блога. Тёмно-синие карточки кейсов с крупными цифрами создают контраст. Визуальные ориентиры — сдержанная редакционная подача Typology и тёплая палитра Dae, без копирования их материалов. В разделе `#cases` размещены показатели трёх проектов из скриншотов владельца: строительство, игровые приставки и юридические услуги. Периоды не одинаковы, контакты не обозначаются как продажи. PNG-карточки 1080×1350 для скачивания находятся в `assets/cases/`; при изменении чисел обновляйте и HTML, и изображения. Отзывы не добавлялись.

Опыт «3+ года» и «20+ ниш», перечень услуг и рекламный текст предоставлены владельцем. Фотография получена из предоставленного владельцем PDF; исходный JPEG извлечён без изменения изображения и сохранён в `assets/ninel-khramova.jpg`. На первом экране используется CSS-кадрирование; файл также указан в Open Graph и разметке Person.
