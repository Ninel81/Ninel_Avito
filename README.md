# Сайт авитолога

Адаптивный статический сайт на HTML, CSS и JavaScript. Зависимости и сборка не требуются.

## Локальный запуск

```sh
cd /workspace/Ninel_Avito
python3 -m http.server 3000 --bind 127.0.0.1
```

## Vercel

В Vercel выберите **Add New → Project**, подключите GitHub и импортируйте `Ninel81/Ninel_Avito`. Production Branch: `main`, Framework Preset: `Other`, корень проекта — корень репозитория. Build Command оставьте пустым, Output Directory — `.`. Нажмите Deploy. Секреты не нужны.

## Перед публикацией

Добавьте подтверждённые имя, контакты и сведения об услугах. Форма сейчас только составляет текст заявки локально; она не отправляет данные. Не добавляйте вымышленные отзывы, кейсы или показатели. Внешний шрифт загружается с Google Fonts; при недоступности используется Arial.

Презентация https://tenway.club/course/presentation.html пока недоступна из среды (прокси возвращает 403), поэтому её содержание ещё не учтено.
