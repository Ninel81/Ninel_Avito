Политика обработки персональных данных

Редакция от 20 октября 2026 года

Эта политика описывает работу формы на сайте Нинель Храмовой и обработку сведений, которые посетитель самостоятельно передаёт для консультации по продвижению на Авито.

1. Кто получает обращение

Нинель Храмова — авитолог, получатель заявок и оператор данных, переданных ей для ответа. Контакт по вопросам персональных данных: чат по объявлению Авито, ссылка в конце этой страницы.

2. Данные и цели

Имя, Telegram или номер телефона и добровольно указанная информация о бизнесе, профиле и задаче используются для ответа, консультации и согласования услуг. Не указывайте данные других людей, пароли, документы и платёжные реквизиты. Для рассылок и публикации отзывов или кейсов с персональными данными потребуется отдельное основание; согласие в форме таких действий не разрешает.

3. Подготовка заявки в браузере

Введённые сведения обрабатываются локальным JavaScript для подготовки текста. Форма не выполняет сетевую отправку, не использует базу данных и не сохраняет значения в localStorage или cookies. После перезагрузки форма не восстанавливается кодом сайта; автозаполнение может выполняться самим браузером по настройкам пользователя. Без JavaScript поля формы отключены.

4. Передача сообщения

Нинель получит заявку только после самостоятельной отправки посетителем в чат Авито. Далее для ответа может использоваться указанный в сообщении контакт. У площадок и средств связи есть собственные условия обработки данных. На сайте не подключены рекламные пиксели, системы аналитики или рассылки.

5. Технические обращения к сайту

Сайт размещён на Vercel. Открытие страницы и загрузка файлов создают технические запросы к хостингу, которые могут содержать IP-адрес, URL, время запроса и сведения о браузере. Работа хостинга регулируется также политикой Vercel. Это отличается от отправки содержания заявки: сервер формы для сбора заявок не используется.

6. Основание и срок

Для ответа на добровольное обращение используется отдельное согласие посетителя. Данные обрабатываются в объёме, необходимом для заявленной цели, до её достижения либо отзыва согласия, если закон не требует их дальнейшего хранения. Для последующего договора могут применяться иные предусмотренные законом основания.

7. Права и безопасность

Можно запросить сведения об обработке, исправление, прекращение обработки или удаление данных. Запрос направляется Нинель в чат Авито с темой «Персональные данные». Для проверки запроса используйте тот же контакт, с которого отправлялась заявка. Доступ к полученным обращениям должен быть ограничен лицами, которым он необходим для ответа; данные не предназначены для публичного распространения.

8. Изменения

При подключении автоматической отправки, CRM, аналитики, рассылок или другого способа сбора данных политика и согласие должны быть обновлены до начала такой обработки. Текущая редакция относится к локальной форме подготовки сообщения.
