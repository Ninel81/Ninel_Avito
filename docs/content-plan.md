## Шаблон статьи

Один вопрос → прямой ответ в начале → шаги проверки → ограничения и примеры → следующий шаг. В поле автора — Нинель Храмова; дата только фактическая. Учебные расчёты подписываются, кейсы и отзывы публикуются только с доказательствами и разрешением. Правила Авито проверять по актуальной справке, не обещать обход модерации.
